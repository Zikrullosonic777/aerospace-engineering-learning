# Orbital Mechanics Simulator 🚀

## Objective
Explore the motion of satellites and other objects under gravitational forces using mathematical models and Python.

## Topics
- Newton's law of universal gravitation
- Circular orbits
- Elliptical orbits
- Orbital velocity
- Orbital period
- Gravitational acceleration

## Planned Technologies
- Python
- NumPy
- Matplotlib

## Planned Features
- Calculate orbital velocity.
- Calculate orbital periods.
- Visualize orbital trajectories.
- Compare different orbital parameters.

## Learning Outcomes
Understand fundamental orbital mechanics and apply mathematics to space-related problems.
